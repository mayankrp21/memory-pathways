05 · SUBSEQUENT USER RETURN

Could engaged users have returned anyway?

Compare raw return rates, then standardize across prior engagement and opportunity type. Return is an activity measure, not a memory-quality score.

ASSOCIATION ≠ CAUSATION
!
Why the crude comparison can mislead

Already-active users may be more likely to encounter retrieval and more likely to return. If so, a raw gap gives memory credit for behavior that may have happened anyway.

06 · METHOD & WHAT NEXT

What can this project conclude?

It can demonstrate an analysis framework and teach the limits of observational retention comparisons. It cannot establish ChatGPT product findings.

Read the measurement contract ↗
A

Grounding

The assistant interacts with the user or another external environment. We measure observable response support and user feedback.

B

Retrieval

The system reads long-term memory into the active workspace. We record segment, result status, relevance, and freshness.

C

Reasoning

The assistant combines current and retrieved information. We evaluate the visible answer; we do not collect private chain-of-thought.

D

Learning

The system writes, updates, or deletes long-term memory. We check correction persistence and forget compliance.

NEXT IN THE RESEARCH

From a synthetic demo to credible evidence

  1. Publish the opportunity rules, event schema, review rubric, and generator assumptions.
  2. Stress-test missing telemetry, small segment groups, overlapping retrieval, and incomplete follow-up.
  3. For real product evidence, instrument exact turn-to-memory links and memory writes in a system you are authorized to study.
  4. For a causal retention claim, design a safe experiment among eligible opportunities and track quality, complaints, privacy, and user control as guardrails.
